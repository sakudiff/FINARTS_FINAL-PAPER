\section{Replication Materials}

All data processing pipelines, estimation scripts, and interactive visualizations associated with this study are publicly accessible through two primary open-access repositories:

\begin{itemize}
    \item \textit{Interactive Web Data Pipeline Report}
\newline \href{https://finalprojectfinartsg4.netlify.app}{\texttt{https://finalprojectfinartsg4.netlify.app}}
\newline Deployed interactive report reproducing all data cleaning steps, diagnostic figures, impulse response grids, and empirical cross-validation tables.

    \item \textit{GitHub Source Repository}
\newline \href{https://github.com/sakudiff/FINARTS_FINAL-PAPER}{\texttt{https://github.com/sakudiff/FINARTS\_FINAL-PAPER}}
\newline Public source code repository containing the unified estimation pipeline (\texttt{scripts/replicate\_svar.py}), Quarto data processing notebook (\texttt{data\_pipeline.qmd}), historical vintage data snapshots, and full-resolution graphics under \texttt{data/processed/var\_results/figures/}.
\end{itemize}
