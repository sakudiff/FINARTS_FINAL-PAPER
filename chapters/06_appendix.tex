\section{Replication Materials}

\newcommand{\plurl}[1]{\textcolor{chi45}{\url{#1}}}
\newcommand{\plink}[2]{\textcolor{chi45}{\href{#1}{\underline{#2}}}}
\newcommand{\plref}[2]{\textcolor{chi45}{\hyperref[#1]{\underline{#2}}}}


All data processing pipelines, estimation scripts, and interactive visualizations associated with this study are publicly accessible through two primary open-access repositories:

\begin{itemize}
    \item \textit{Interactive Web Data Pipeline Report}
\newline \plurl{https://finalprojectfinartsg4.netlify.app}
\newline Deployed interactive report reproducing all data cleaning steps, diagnostic figures, impulse response grids, and empirical cross-validation tables.

    \item \textit{GitHub Source Repository}
\newline \plurl{https://github.com/sakudiff/FINARTS_FINAL-PAPER}
\newline Public source code repository containing the unified estimation pipeline (\texttt{scripts/replicate\_svar.py}), Quarto data processing notebook (\texttt{data\_pipeline.qmd}), historical as-of-date data snapshots, and full-resolution graphics under \texttt{data/processed/var\_results/figures/}.
\end{itemize}
