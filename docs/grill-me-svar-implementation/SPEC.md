## 5. Lag Selection

- **Criterion:** AIC (Akaike Information Criterion)
- **Max lags searched:** 20
- **Implementation:** `statsmodels.tsa.var_model.VAR.fit(maxlags=20, ic='aic')`

## 6. Pre-estimation Diagnostics

### 6.1 Stationarity (ADF Tests)

- **Test:** Augmented Dickey-Fuller on each transformed variable as-is (log levels, percentages, binary)
- **Null hypothesis:** Variable has unit root
- **Significance:** 5%
- **Report:** For each variable: ADF statistic, p-value, verdict (stationary / non-stationary)
- **Action if non-stationary:** Flag in output; do not difference (paper states all are stationary)

### 6.2 Risk-off Binary Construction Verification

- Confirm `risk_off` matches paper definition: VIX ≥ rolling 60-day MA + 10pp
- First 59 observations will be NaN — drop them

## 7. Restricted VAR Implementation

### 7.1 Approach

Use `statsmodels.tsa.var_model.VAR.fit_constrained()` to enforce zero constraints during optimization.

The restriction matrix R and constraint vector q are defined such that for the Risk-off equation (equation 1):

- Coefficients on lagged **WUI, Spread, RGDP, REER, Stock Index, Debtsec, Equity, Other, Direct** = 0
- Coefficients on lagged **Risk-off** and **exogenous variables** are free

Construction per `fit_constrained` API:
```python
# R matrix: (n_constraints × n_params) where each row is one constraint
# For 10 vars × k lags + n_exog params, constrain the 9 non-Risk-off variables
# across all lags

# Alternative: Use formula-like string constraints
# e.g., "Risk-off.L1.WUI = 0, Risk-off.L1.Spread = 0, ..."
```

### 7.2 Fallback

If `fit_constrained()` fails (singularity, convergence issues):
1. Estimate Risk-off equation via OLS using only its own lags + exogenous variables
2. Estimate remaining 9 equations via standard VAR (with Risk-off lags included)
3. Combine into a single VARResults-compatible object for IRF computation

### 7.3 Unrestricted VAR

Standard `VAR.fit()` with no constraints — all variables on all lags.

## 8. IRF Computation

### 8.1 Parameters

| Parameter | Value |
|-----------|-------|
| Shock variable | Risk-off (position 0) |
| Shock size | One standard deviation |
| Horizon | 125 steps (working days, ~6 months) |
| Identification | Cholesky (ordering as in Section 3) |

### 8.2 Confidence Intervals — Two Methods

**Method A — Analytical (asymptotic normal):**
- `statsmodels` default via `irf.plot(stderr='asymptotic')`
- Assumes normally distributed residuals
- Fast, matches standard software output

**Method B — Bootstrap (residual-based):**
- `irf.plot(stderr='bootstrap', B=1000)` in `statsmodels` OR manual implementation
- Re-samples residuals with replacement, re-estimates IRFs for each replication
- Takes 2.5th and 97.5th percentiles across replications
- Justification: *"Given evidence of non-normality in capital flow variables (other_pct skew, risk_off binary), we also compute bootstrap confidence intervals (1,000 replications) as a robustness check on the analytical intervals."*

### 8.3 Comparison Protocol

For each model × period combination, produce:
1. IRFs with **analytical CIs** — default matching paper
2. IRFs with **bootstrap CIs** — robustness
3. **Overlay comparison** — where possible, compare shape/magnitude/timing against Beirne & Sugandi (2023) Figures 4–10
